# pomodoro_plus

**pomodoro_plus** is a project written in python that aims to enchance one´s studying and assist them in avoiding procrastination. Classical pomodoro timers use a 25/5 minute study/break split that can often be too restrictive as well as destracting. **pomodoro_plus** aims to give more leeway in terms of breaks by aiming for more spontaneous study and break sessions with the ultimate goal being that the user specified study time is achieved.

## Project Status

This project is currently in prototyping phase.
